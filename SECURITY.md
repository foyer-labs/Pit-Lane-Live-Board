# Security policy

*Italiano in fondo.*

Pit Lane Live Board handles one secret: the optional F1TV token, which must never leave
the Home Assistant backend (SPEC, INV-3).

If you find a way it can leak (through the panel, a WebSocket command, an entity,
diagnostics or logs), or any other vulnerability, report it **privately** through
GitHub's
[private vulnerability reporting](https://github.com/foyer-labs/Pit-Lane-Live-Board/security/advisories/new),
not in a public issue.

Reports are handled as time allows, with no promise of a timeline; this is a personal,
non-commercial project. Only the latest release is fixed.

---

**Italiano.** L'unico segreto che l'integrazione custodisce è il token F1TV facoltativo,
che non deve mai uscire dal backend di Home Assistant.

Se trovi un modo in cui può trapelare, o un'altra vulnerabilità, segnalala **in privato**
con la
[segnalazione privata di vulnerabilità](https://github.com/foyer-labs/Pit-Lane-Live-Board/security/advisories/new)
di GitHub, non in una issue pubblica.

Si corregge solo l'ultima release, senza impegno sui tempi.
